# L.O.R — Site institucional

Site de página única da L.O.R (engenharia elétrica e automação industrial).
Arquivo único, sem build: `index.html` já contém CSS, fontes, imagens e componentes embutidos.

## Publicar no GitHub Pages
1. Crie um repositório novo no GitHub (ex: `lor-site`).
2. Envie o conteúdo desta pasta para a branch `main` (arraste os arquivos em *Add file → Upload files*).
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `/ (root)` → Save.
4. Em ~1 min o site fica em `https://<usuario>.github.io/<repo>/`.

## Arquivos
- `index.html` — site completo (offline-ready)
- `.nojekyll` — desativa o Jekyll no Pages
